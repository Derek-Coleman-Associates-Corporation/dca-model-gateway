# Gateway QA — November 12, 2026

DCAI tested the Gateway with synthetic prompts and temporary test keys. No customer prompts or credentials are published here.

| Check | Result |
|---|---|
| Starter plan contract | Six contract tests passed; existing Team/Partner settings preserved |
| Application regression | 171 .NET cases passed; buyer application compiled successfully |
| Live Starter lifecycle | 14 checks passed: key cap, unconnected-provider refusal, suspend, reinstate, revoked-key preservation, cancel and cleanup |
| Customer-provider connection contract | 21 checks passed, including authentication, route mapping, boundary declarations, disabled connection and endpoint restrictions |
| Initial inference evaluation | 14 of 15 requests returned HTTP 200 with correct answers and reconciled token totals; one US DeepSeek request was rate-limited |
| Rate-limit recovery | Repeated burst reproduced provider throttling; an isolated retry after cooldown succeeded |
| Llama streaming | HTTP 200, correct answer, completed SSE stream and reconciled usage; first content at 1,557 ms |
| Negative requests | Missing/invalid key, invalid boundary and missing US twin all rejected as expected |

The three evaluation tasks were arithmetic, extracting specified fields into JSON and answering “unknown” when the supplied passage lacked an answer. Successful initial responses had median latency 2,045.5 ms. These are small smoke tests, not a broad quality benchmark, load test or SLA. Model routes and qualifications are in [open-weight model support](open-weight-models.md).

The US DeepSeek deployment returned `429` and `Retry-After: 56` during a follow-up burst. Respect Retry-After, use bounded backoff with jitter and limit concurrency. The provider can throttle below the Gateway plan's cap.

QA found and fixed a reinstatement delay for extra tenant keys. Reinstatement now aligns eligible extra keys immediately while keeping revoked keys disabled. In-place changes to/from Starter remain blocked until billing can segment usage by plan effective date; new subscriptions and renewals are supported.

Billing regression tests used a controlled transport test double. No paid Marketplace purchase or invoice settlement was tested. A commercial pilot and first-invoice reconciliation remain necessary to verify end-to-end billing. Starter publication status is shown in [limits and billing](limits-and-billing.md); a saved draft price is not proof of purchase availability.

Boundary checks verify the Gateway's enforcement of customer declarations and configured routes. They do not independently certify a cloud provider's physical processing location. No claim is made that all open-weight models, tools, embedding models or streaming variants were tested.

Source implementation, repeatable operator scripts and sanitized machine-readable evidence are kept in DCAI's private production GitHub repository. The public documentation and samples retain their existing MIT license; model weights and provider services have their own terms.

Publication follow-up — November 13, 2026: Microsoft completed the live submission, and the public Plans + Pricing page displays Starter at $79/month with the 20M/5M token allowances and one included active key. No paid purchase or invoice was performed by this follow-up.
